# Verification

## Strategy

Verification combines self-checking Verilog testbenches, static hierarchy checks, C++17 CModel tests, and cycle-by-cycle RTL/CModel trace comparison.

## Testbench Coverage

| Testbench | Coverage |
|---|---|
| `tb_sr_reset_semantic.v` | Reset assertion and valid-state clearing |
| `tb_sr_leaf_semantic.v` | Propagation, Inject, and Consume behavior |
| `tb_sr_leaf_cell_semantic.v` | Cell isolation, collision, and invalid consume |
| `tb_sr_column_compliance.v` | Stateless wrapper and one-cycle column hop |
| `tb_sr_basic_pipeline.v` | Basic fixed-latency Pipeline |
| `tb_sr_direction_fabric.v` | Eastward/Westward flow and bubble preservation |
| `tb_sr_hemisphere_fabric.v` | Independent directional paths |
| `tb_sr_fabric.v` | Top-level path independence |
| `tb_sr_default_profile.v` | Default configuration elaboration |
| `tb_sr_saturated_stream.v` | Continuous streaming traffic |
| `tb_sr_saturated_full_profile.v` | All-cell stress stimulus |
| `tb_sr_hop_trace.v` | Per-column timing and RTL trace generation |

All testbenches report `TEST_PASS` or `TEST_FAIL`.

## Static Checks

- `check_module_names.py` checks file/module naming and direct hierarchy relationships.
- `check_dependencies.py` checks that RTL instances remain within the documented module set.
- `check_dimensions.py` checks parameter defaults, packed widths, interface shape, and leaf-only state ownership.
- `check_public_release.py` checks repository contents, sensitive naming, paths, links, and generated artifacts.

## CModel and Trace Comparison

The C++ model advances one cycle per `step()` call and mirrors directional cell propagation. `tb_sr_hop_trace.v` and `test_cmodel.cpp` can generate matching CSV traces under `sim/trace`; `compare_rtl_cmodel.py` performs exact row comparison and an independent hop-timing check.

## Waveform Debugging

Waveforms are not committed and are not generated by the default scripts. For local debugging, enable a VCD dump in the selected testbench or simulator command. `.gitignore` excludes `*.vcd`, `*.vvp`, `sim/`, and build products.
